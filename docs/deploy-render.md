# Publishing on Render (free tier)

`render.yaml` at the repository root describes three free resources: a Postgres database, the API (Docker) and the Angular site (static, with `/api/*` proxied to the API).

1. Sign in at https://render.com with GitHub and choose **New > Blueprint**, then select this repository.
2. Apply the blueprint. The first build of the API takes several minutes.
3. Open the `jobmatcher-api` service and check its URL. If it is not `https://jobmatcher-api.onrender.com` (the name was taken), edit the `/api/*` rewrite in `render.yaml` (or in the `jobmatcher-web` service, **Redirects/Rewrites**) to match.
4. Open the URL of `jobmatcher-web`.

## Limits of the free tier

- The API has 512 MB of RAM. Spring Boot with Tika is tight; if the service restarts with out-of-memory errors, move it to the Starter plan.
- Free web services sleep after 15 minutes without traffic; the first request afterwards takes about a minute.
- The free Postgres database expires after 30 days. Upgrade it or export the data before then.
- No Ollama: `AI_PROVIDER=mock`, so grammar review returns nothing. Letters and matching still work (they are deterministic).
- `APP_ENCRYPTION_KEY` is generated by Render. Do not delete it; stored CVs cannot be read without it.
- Anyone with the address can register; keep Tanitjobs disabled.
